Como desbloquear o CMD: 
 

 
 

  1. Pressione Windows + R 

  2. Digite:  
    gpedit.msc 
     

  3. Navegue até:  
    Configuração do Usuário > Modelos Administrativos > Sistema 
     

  4. Procure a opção: → Impedir acesso ao prompt de comando 

  5. Clique duas vezes e marque: → Desativado ou Não configurado 

  6. Clique em Aplicar > OK 

 
 

✅ 2. Ajuste via Registro (caso não tenha gpedit) 

  1. Pressione Windows + R 

  2. Digite: 
    regedit 
     

  3. Vá até o caminho: 
    HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\System 
     

  4. No lado direito, encontre: → DisableCMD 

  5. Altere o valor: 

    • 0 = permitido 

    • 1 = bloqueado 

✔️ Defina como 0 ou exclua a chave
